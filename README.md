# LoRA from Scratch → Text-to-SQL

LoRA implemented from first principles in PyTorch, **verified to match Hugging Face PEFT
numerically**, then used to fine-tune a small LLM into a text-to-SQL model judged by
**running its queries against real databases**.

> Status: scaffold. Fill in the results tables below as you run experiments.

## Highlights

- `LoRALinear` in ~80 lines of plain PyTorch: frozen base, low-rank `A`/`B`, `alpha/r` scaling,
  rsLoRA scaling, adapter dropout, **merge / unmerge** into the base weight.
- Model surgery that swaps target `nn.Linear` layers in any HF model (`inject_lora`).
- A hand-written training loop: gradient accumulation, gradient checkpointing, cosine schedule,
  grad clipping, **LoRA+** (separate LR for `B`), throughput and peak-memory logging.
- Same config trains with either backend (`backend: scratch | peft`) for a head-to-head comparison.
- Evaluation by **execution accuracy** on Spider (read-only SQLite, timeouts, order-aware row comparison).

## How LoRA works (the 30-second version)

For a frozen weight `W ∈ R^{out×in}`, LoRA learns `ΔW = (α/r)·B·A` with
`A ∈ R^{r×in}`, `B ∈ R^{out×r}`, `r ≪ min(in, out)`:

```
y = W x + (α/r) · B (A x)
```

`B` starts at zero, so training starts from exactly the base model. Only `r·(in+out)`
parameters per layer are trained instead of `in·out`. After training, `ΔW` can be added
into `W`, so inference costs nothing extra. See [`src/lora_sql/lora.py`](src/lora_sql/lora.py).

## Repo layout

```
configs/qwen05b_sql.yaml    all hyperparameters (override any with --override key=value)
```

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
```

Runs on a free Colab T4, a single consumer GPU, or Apple Silicon (MPS).

## Usage

```bash
# 1. Baseline: the base model, no fine-tuning
python scripts/eval_sql.py --config configs/qwen05b_sql.yaml --limit 500

# 2. Train with the from-scratch LoRA
python scripts/train.py --config configs/qwen05b_sql.yaml

# 3. Same run with HF PEFT, for comparison
python scripts/train.py --config configs/qwen05b_sql.yaml \
  --override backend=peft train.output_dir=outputs/qwen05b-r16-peft

# 4. Evaluate an adapter (add --merge to fold it into the weights first)
python scripts/eval_sql.py --config configs/qwen05b_sql.yaml --adapter outputs/qwen05b-r16 --limit 500

# 5. Execution accuracy on Spider dev (download Spider into data/spider first)
python scripts/eval_sql.py --config configs/qwen05b_sql.yaml --adapter outputs/qwen05b-r16 \
  --benchmark spider --spider-dir data/spider

# 6. Rank ablation
bash scripts/rank_sweep.sh
```
